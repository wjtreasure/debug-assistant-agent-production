# Issue Triage
Identify exact anchors first: file paths, symbols, exception names, stack frames, configuration keys, and quoted error text. If anchors are absent, describe the behavior and subsystem precisely enough to form a semantic information need.

## Completion Criteria
- expected and actual behavior are separated
- at least one actionable search anchor or conceptual information need exists
