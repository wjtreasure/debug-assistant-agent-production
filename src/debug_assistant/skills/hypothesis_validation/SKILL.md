# Hypothesis Validation
Prioritize direct implementation evidence. Then use a caller, test, related implementation, or git history as independent support. Resolve direct contradictions before optional validation. Do not keep creating optional evidence gaps after the causal mechanism is already source-backed.

## Completion Criteria
- at least one direct source-code causal evidence item exists
- at least one independent supporting evidence item exists when available
- no unresolved critical contradiction remains
